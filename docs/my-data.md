# My Lab Data

Everything you have typed into the lab worksheets, gathered onto one page so you
can copy it into your report without retyping numbers off the bench.

This reads what is saved in **this browser**. If you filled a table on a lab PC
and are now on your laptop, it will look empty — use the same browser, or
download the Markdown while you are still on the machine you used.

Nothing here is written for you. Empty fields stay empty.
